# Annotation Agreement Report

**Provenance:** labels were produced by two independent **AI coders** (coder A = Claude Sonnet, coder B = Claude Haiku),
each seeing only an opaque id and the privacy-masked text, following `annotation_guide.md`. Disagreements were resolved
by an AI adjudicator (Claude Sonnet) shown both labels and the guide. Per the project owner's decision these serve as the
reference labels; they are **not** independent human gold, and κ below is **inter-AI-annotator** agreement.

Generated by `scripts/build_labels.py`. Items: 2000 (pilot 100, main 1900).

## Blind third-model audit
A third model (Claude Opus, the session's default model) relabelled 180 items **blind** (text + guide only): 120 random A/B disagreements and 60 random agreed items (`data/annotation/audit_design.csv`). It measures how often an independent coder reproduces the reference label.

| subset | n | audit = final | audit = coder A | audit = coder B | audit = final (complaint yes/no/unclear only) |
|---|---|---|---|---|---|
| disagreements | 120 | 0.800 | 0.775 | 0.158 | 0.850 |
| agreed | 60 | 0.950 | 0.950 | 0.950 | 0.967 |

## Quality incidents (kept for transparency)
- Pilot: coder B's first run produced no labels (it wrote an unrelated plan); it was re-run with a strict labeling-only prompt.
- Batch `main_05`: coder B's first output was degenerate (30 complaints vs 92–124 in every other batch; it missed obvious complaints such as "ما يرضى يشتغل"). It and the adjudication built on it were moved to `out/rejected/`; coder B re-labelled the batch (prompt with an added reminder that short texts can report concrete problems) and it was re-adjudicated.
